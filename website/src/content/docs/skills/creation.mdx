title: Creation Skills
description: Content and artifact creation capabilities.
---

Creation skills focus on generating new content, code, and artifacts.

## Available Skills

| Skill | Purpose | Common Personas |
|-------|---------|-----------------|
| **Document Generation** | Create structured documents | All personas |
| **Code Generation** | Write new code | Kestra |
| **Diagram Creation** | Create visual diagrams and flowcharts | Kestra |
| **Plan Drafting** | Create project plans and roadmaps | Hopper, Lovell |
| **Report Writing** | Write analytical reports | Clara, Watson, Goeth |

## Document Generation

Create structured documents following templates or requirements.

**When to Use:**
- Creating specifications
- Writing procedures
- Drafting communications
- Preparing presentations

**Inputs Required:**
- Purpose and audience
- Key content points
- Format requirements
- Templates (if any)

**Outputs Produced:**
- Complete document
- Table of contents
- References (if applicable)

## Code Generation

Write new code following best practices and requirements.

**When to Use:**
- Implementing new features
- Creating utilities or scripts
- Prototyping solutions
- Generating boilerplate

**Inputs Required:**
- Requirements or specifications
- Technology constraints
- Coding standards
- Integration context

**Outputs Produced:**
- Working code
- Comments and documentation
- Test suggestions
- Usage examples

## Diagram Creation

Create visual diagrams and flowcharts (described textually or as ASCII/Mermaid).

**When to Use:**
- Architecture documentation
- Process flows
- System relationships
- Decision trees

**Inputs Required:**
- Subject to diagram
- Level of detail
- Preferred format

**Outputs Produced:**
- Diagram (ASCII, Mermaid, or description)
- Legend/key
- Explanatory notes

## Plan Drafting

Create project plans and roadmaps.

**When to Use:**
- Project kickoff
- Sprint planning
- Roadmap development
- Resource allocation

**Inputs Required:**
- Goals and objectives
- Constraints (time, budget, resources)
- Dependencies
- Stakeholders

**Outputs Produced:**
- Phased plan
- Milestones and deliverables
- Risk identification
- Resource requirements

## Report Writing

Write analytical reports with findings and recommendations.

**When to Use:**
- Summarizing research
- Presenting analysis
- Documenting decisions
- Communicating to stakeholders

**Inputs Required:**
- Analysis or findings
- Audience and purpose
- Format requirements
- Key questions to answer

**Outputs Produced:**
- Executive summary
- Detailed findings
- Recommendations
- Appendices (if needed)
