## Help

Discover and learn about framework components, personas, patterns, and skills.

**When to Use:**
- New to the framework
- Looking for the right persona
- Understanding available patterns
- Finding appropriate skills

**Inputs Required:**
- Question or topic of interest
- Optional: specific category (personas, patterns, skills)

**Outputs Produced:**
- Relevant component suggestions
- Usage guidance
- Examples
- Links to documentation

### Example Usage

```text
User: Which persona should I use for financial analysis?

Help response:
For financial analysis, consider Clara - Financial Analyst.

Clara specializes in:
- Equity valuation (DCF, comparables, factor exposure)
- Macro and sector trend interpretation
- ETF vs single-asset portfolio construction
- Risk management and hedging tactics
- Scenario and sensitivity analysis

Recommended patterns: rule-based-reasoning, chain-of-thought
Primary skills: financial-modeling, risk-assessment, data-analysis

Example invocation:
Persona: Clara. Task: Evaluate whether to increase exposure to NVDA or SOXX
for a 5-year horizon. Patterns: rule-based reasoning + chain-of-thought.
```
