Patterns are the **HOW** of AI Mantras - reusable reasoning structures and thinking templates that provide consistent, traceable outputs. They work like mental frameworks that guide how AI approaches different types of problems.

## Pattern Layers

AI Mantras includes 11 patterns organized into three layers based on their function:

<CardGrid>
  <Card title="Layer 1: Foundational" icon="setting">
    **Core workflow patterns**

    Planning, orchestration (linear and graph), self-evaluation, and meta-rules that govern all work.
  </Card>
  <Card title="Layer 2: Thinking" icon="puzzle">
    **Reasoning patterns**

    Chain-of-thought, rule-based reasoning, agentic loops, and creative guardrails for execution.
  </Card>
  <Card title="Layer 3: Evaluation" icon="approve-check">
    **Assessment patterns**

    Criterion-based evaluation and threat modeling for quality and safety.
  </Card>
</CardGrid>

## Common Combinations

Patterns work together in powerful combinations:

| Workflow | Pattern Combination |
|----------|---------------------|
| **Project kickoff** | Planning Phase → Orchestration → Meta Rules |
| **Domain execution** | Chain of Thought + Rule-Based Reasoning |
| **Creative work** | Guardrail Creative + Meta Rules |
| **Quality review** | Criterion-Based Evaluation + Recursive Self-Eval |
| **Security assessment** | Threat Modeling + Rule-Based Reasoning |
| **High-stakes work** | Any pattern + Recursive Self-Eval |
| **Autonomous agents** | Agentic Loop + Criterion-Based Evaluation |
| **Multi-agent workflows** | Graph Orchestration + Agentic Loop (per worker) |

## How to Use Patterns

1. **Embed patterns in prompts** - Include the pattern template verbatim so personas follow the structure
2. **Combine patterns** - Stack multiple patterns for complex tasks
3. **Follow recommended patterns** - Each persona lists which patterns work best
4. **Reference during QA** - Verify outputs follow the pattern structure
